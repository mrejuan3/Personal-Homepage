My Projects

Life Insurance Power Dialer

A calling system that works through life insurance brokers' lead lists automatically. Live answers are bridged straight to the broker, and voicemails are filtered out. Safeguards respect do-not-call lists and calling hours, and a dashboard lets the client run it on their own.

SideQuest Web Application

A full-stack platform that connects students with collaborators from other disciplines. Students can browse projects and search for teammates by category and technology. Built with React, Node.js, Express, and MongoDB, with secure logins and a cloud deployment.

BreastCare Decision Support Tool

A decision support platform that helps clinicians guide breast cancer care. Machine learning models predict tumor malignancy, patient risk, and long-term survival. Clinicians enter patient data in a web app, compare patients side by side, and download reports.

Exoplanet Exploration

A machine learning model that sorts NASA-confirmed exoplanets into four planet types. It's built to help astronomers narrow the search for Earth-like worlds. Rare rocky planets were missed at first, so the model was rebalanced and tuned to catch them.

NLP Analysis of Tweets by Global Leaders

An interactive dashboard on how global leaders portray world issues on Twitter. Tweets were collected and analyzed with natural language processing to compare topics and sentiment. Results are shown through Sankey diagrams, bar charts, and an interactive world map.

Nurturing Mental Health Through Trees

A data report for Boston streetscape stakeholders on how canopy trees support mental health. Made with community partner Speak for Trees to advocate for tree equity and open space. It draws on Boston's open data to help shape future urban planning.

Evolutionary Computing for Resource Allocation

A program that assigns teaching assistants to lab sections using evolutionary computing. Agents repeatedly modify existing schedules to reduce overallocation and time conflicts while honoring TA preferences. Unit tests check its output against sample solutions.

Data Science Salary Predictions

An exploratory analysis of the features that most affect data science salaries. Linear and SGD regression models and heat maps measure each feature's impact. The results are shown through bar plots, an interactive scatterplot, and an interactive world map.

Correlations in Autism Research and Political Partisanship

A sentiment analysis of how news outlets' political partisanship relates to autism coverage. It charts diagnosis rates alongside state partisanship and poverty using CDC and census data. Maps and pie charts show state leanings and representation in autism research.
